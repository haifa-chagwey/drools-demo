BRE – Business Rule Engine

A BRE is the core engine that evaluates rules.

It is the technical component that:

receives data (facts)

checks rules

executes actions

returns a decision

Examples of BREs:

Drools

Easy Rules

RuleBook

BRMS – Business Rule Management System

A BRMS is a complete platform to manage rules.

It usually includes:

a rule engine (BRE) inside it

web interface for business users

rule versioning

testing tools

deployment management

rule repositories

Examples:

IBM Operational Decision Manager

Oracle Business Rules

Red Hat Decision Manager
